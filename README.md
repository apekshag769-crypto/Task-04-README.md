# Task 04 — Twitter Entity Sentiment Analysis

## 📌 Project Overview

This project analyzes Twitter social media data to understand sentiment
patterns and public opinion toward different entities and topics.

The project uses Python, Pandas, Matplotlib, and WordCloud for data
analysis, text processing, and visualization.

## 🎯 Objectives

- Analyze Positive, Negative, and Neutral sentiments
- Identify the most discussed entities
- Compare sentiment patterns across entities
- Identify frequently used words
- Visualize sentiment patterns
- Generate a word cloud from tweet data

## 📊 Dataset

The project uses the Twitter Entity Sentiment Analysis dataset.

The dataset contains:

- Tweet ID
- Entity
- Sentiment
- Tweet text

## 🛠️ Technologies Used

- Python
- Pandas
- Matplotlib
- WordCloud
- Google Colab

## 🔍 Analysis Performed

1. Loaded the Twitter dataset
2. Checked missing values and duplicate records
3. Cleaned the dataset
4. Analyzed overall sentiment distribution
5. Identified the most discussed entities
6. Compared sentiment across entities
7. Calculated sentiment percentages
8. Performed text preprocessing
9. Identified frequently used words
10. Created charts and a word cloud

## 📈 Visualizations

- Overall Sentiment Distribution
- Top 10 Most Discussed Entities
- Sentiment Comparison by Entity
- Sentiment Percentage by Entity
- Top 20 Most Common Words
- Twitter Sentiment Word Cloud

## 💡 Conclusion

The project demonstrates how social media data can be analyzed to
identify sentiment patterns and understand public opinion toward
different entities.

The results are based on the tweets contained in the dataset and are
intended for exploratory data analysis.
